# Jinxiu Rally · 锦绣飞车

## 简介 · Introduction

锦绣飞车是基于[新白鹭引擎 Egret Rebuild](https://github.com/cnedwin/Egret_rebuild)独立开发的 3D 赛车游戏 Demo。八位带着中国元素的车手在“山水环道”上同场竞速：过牌楼、上山坡、穿 S 弯、跨石桥、绕发卡弯，漂移攒出加速，捡铜钱、穿祥云门、借前车尾流，绕开泥潭、石狮和滚动的大鼓，再用爆竹、蹴鞠、纸鸢、筋斗云和窜天猴扭转名次。 [在线试玩](https://cnedwin.github.io/PortedGamesEgret/Rally/)

Jinxiu Rally is an independently developed 3D kart racing demo built with [Egret Rebuild](https://github.com/cnedwin/Egret_rebuild). Eight racers drawn from Chinese tradition share the Mountain and Water Circuit: under the ceremonial gate, up the hill, through the S-bend, over the stone bridge and round the hairpin, drifting for boosts, collecting coins, threading cloud gates and tucking into slipstreams, steering round mud, stone lions and rolling drums, and turning the order around with firecrackers, cuju balls, kites, a somersault cloud and sky rockets. [Play online](https://cnedwin.github.io/PortedGamesEgret/Rally/)

## 玩法 · How to play

| | 键盘 · Keyboard | 手柄 · Gamepad |
|---|---|---|
| 油门 · Accelerate | W / ↑ | A / 右扳机 right trigger |
| 刹车与倒车 · Brake and reverse | S / ↓ | B / 左扳机 left trigger |
| 转向 · Steer | A D / ← → | 左摇杆 · left stick |
| 小跳与漂移 · Hop and drift | Space | RB / X |
| 使用道具 · Use item | E / X / 左 Shift left Shift | LB / Y |
| 回头看 · Look back | C | 按下摇杆 · click a stick |
| 暂停 · Pause | Esc / P | Start |
| 静音 · Mute | M | |

触屏设备会显示屏幕按键，并自动踩住油门。比赛中可点小地图下方的暂停键。

Touch screens get on-screen buttons, and the kart accelerates by itself. Tap the pause button below the minimap during a race.

- 转向时按住漂移键过弯，火花由蓝变橙再变紫，松开后获得相应强度的加速。
- 倒数到“2”之后再踩油门可以弹射起步；踩得太早会熄火。
- 冲过发光的加速带、从木坡道起跳并在空中按漂移键，都能加速；草地会让车慢下来。
- 撞开红灯笼获得道具，名次越靠后越容易拿到强力道具。
- 屏幕下方的漂移条显示离下一级加速还差多少；超车、加速和特技都会有提示。

- Hold drift while steering through a corner: the sparks turn blue, orange, then purple, and letting go gives a boost to match.
- Press the accelerator after the count reaches 2 for a rocket start; too early and the engine stalls.
- Glowing strips give a boost, and so does pressing drift in the air off a wooden ramp; grass slows a kart down.
- Drive through a red lantern for an item. The further back a kart is, the stronger the items it tends to get.
- The drift bar at the bottom shows how close the next boost level is; overtakes, boosts and tricks are called out on screen.

### 赛道上 · On the track

| | 效果 · Effect |
|---|---|
| 铜钱 · Coins | 每枚略微提高极速，最多十枚；被击中会掉三枚 · each adds a little top speed, up to ten; a hit spills three |
| 祥云门 · Cloud gates | 从门中间穿过获得加速 · drive through the middle for a boost |
| 尾流 · Slipstream | 紧跟前车一会儿获得加速 · stay close behind another kart for a moment and get a boost |
| 加速带、木坡道 · Boost strips, ramps | 加速；腾空时按漂移键做特技，落地再加速 · a boost; press drift in the air for a trick and another on landing |
| 泥潭 · Mud | 明显减速并打滑 · slows a kart sharply and makes it slide |
| 石狮 · Stone lions | 撞上会被弹开并损失大半速度 · a bump throws the kart back and costs most of its speed |
| 滚鼓 · Rolling drums | 在路面来回滚动，撞上会打转 · roll from side to side across the road and spin whatever they meet |

三个级别（闲庭信步、策马奔腾、追风逐电）决定车速和对手的水平，可选 1、3 或 5 圈。标题界面可以切换画质（高、中、低）和语言，帧率不足时请调低画质。

Three classes (Stroll, Gallop, Gale) set the speed and how well the rivals drive, over 1, 3 or 5 laps. The title screen switches picture quality (high, medium, low) and language; lower the quality if the frame rate drops.

## 运行与开发 · Run and develop

游戏是纯静态页面，无需构建。在本目录启动任意静态文件服务器，然后打开显示的地址：

The game is a static page with no build step. Start any static file server in this folder and open the address it prints:

```sh
npx serve .
```

地址参数 · Address options：

| 参数 · Option | 作用 · Effect |
|---|---|
| `?lang=zh` / `?lang=en` | 界面语言 · interface language |
| `?backend=webgpu` | 使用 WebGPU 绘制 · draw with WebGPU |
| `?models=original` | 使用原程序模型 · use the original procedural models |
| `?quality=high` / `medium` / `low` | 起始画质 · starting picture quality |
| `?ratio=1` | 限制像素比以提高帧率 · cap the pixel ratio for a higher frame rate |
| `?seed=123` | 固定随机种子 · fix the random seed |

### 测试 · Tests

使用 Node.js 22 或更新版本，在本目录运行：

Use Node.js 22 or later and run from this folder:

```sh
node --test
```

不开页面跑完一整场比赛（参数为级别 0 到 2、圈数、种子，均可省略），八辆车都由游戏驾驶，输出每圈的名次和最终成绩，适合检查规则和数值改动：

Run a whole race without a page (class 0 to 2, laps and seed are optional). The game drives all eight karts and prints the order each lap and the final result, which suits checking changes to rules and numbers:

```sh
node tools/headless.mjs 1 3 7
```

## 引擎用法 · How it uses the engine

游戏使用白鹭 World3D，默认以 WebGL2 绘制。各部分对应的引擎功能如下。

The game uses Egret World3D and draws with WebGL2 by default. Each part maps to an engine feature as follows.

| 引擎入口 / API · Entry / API | 在本游戏中的用途 · Use in this game | 文件 · File |
|---|---|---|
| `CatmullRomCurve3D` 闭合曲线，等距取样 · closed curve, sampled at equal distances | 赛道中心线 · The circuit's centre line | `src/track.mjs` |
| `createGeometry3D` 沿赛道生成的带状网格 · strips generated along the track | 路面、路肩、围墙、桥面 · Road, kerbs, walls, bridge deck | `src/tree-models.mjs` |
| 白鹭 glTF 加载器读取内嵌 PBR 贴图的 GLB，也支持带顶点色的程序网格 · Egret's glTF loader reads GLBs with embedded PBR textures alongside vertex-coloured procedural meshes | 车手、座驾、地标与道具 · Racers, karts, landmarks and props | `src/track-models.mjs` |
| `createLatheGeometry3D` 旋转成形 · spun from an outline | 轮胎 · Tyres | `src/racers.mjs` |
| `InstancedMesh3D` 逐实例变换与颜色 · per-instance transform and colour | 树木、花草、灯笼、旌旗、观众、仙鹤、长城、群山 · Trees, verge plants, lanterns, banners, crowd, cranes, long wall, mountains | `src/scenery.mjs` |
| 每帧重填的 `InstancedMesh3D` · refilled every frame | 道具箱、铜钱、滚鼓与飞行中的道具 · Item boxes, coins, drums and items in flight | `src/scenery.mjs` |
| `createWater3D` 波浪与倒影 · waves and reflection | 湖面 · The lake | `src/scenery.mjs` |
| `createGlassMaterial3D` | 金钟罩 · The golden bell | `src/racers.mjs` |
| `createParticleEmitter3D` | 漂移火花、尾焰、尘土、泥浆、花瓣、烟花 · Drift sparks, flames, dust, mud, petals, fireworks | `src/view.mjs` |
| `createTrail3D` | 加速拖尾、漂移胎痕 · Boost trails, drift tyre marks | `src/view.mjs` |
| `createRingGeometry3D` + 叠加混合 · additive blending | 冲击波光环 · Shock rings | `src/view.mjs` |
| 由像素或画布生成的 `Texture3D` · made from pixels or a canvas | 路面、草地、牌匾、横幅、车徽贴图 · Road, turf, plaque, banner and badge textures | `src/shapes.mjs` |
| Engine 时钟 · Engine clock，`createWorld3DView`，`startWorld3DLoop` | 帧循环 · Frame loop | `src/main.mjs` |
| 级联阴影、天空环境光、雾、环境遮蔽、泛光、FXAA · cascaded shadows, sky lighting, fog, ambient occlusion, bloom, FXAA | 画面 · Look | `src/main.mjs` |

比赛规则（车辆手感、对手驾驶、道具、圈数与名次）可以在 Node 中整局运行。画面使用程序网格和 [Tripo 模型](assets/track-models/README.md)，音乐和音效由代码生成。

The race rules (handling, rival driving, items, laps and places) can run a whole race in Node. The visuals use procedural meshes and [Tripo models](assets/track-models/README.md). Music and sound effects are generated in code.

## 已知问题 · Known issues

- 湖面倒影每三帧才更新一次，快速转弯时倒影会略微滞后。 · The lake's reflection updates every third frame, so it lags a little in fast turns.
- 品质验收未达标 · Quality items failing（[QUALITY.md](QUALITY.md)，2026-11-20，无头 Chromium + SwiftShader · headless, software rendering）：T2 触控区 ≥ 44×44 CSS px（2 of 4 under 44×44: Sound: On 120×41; Quality: High 137×41）；F1 桌面帧时间 p95 ≤ 16.7 ms（p95 1749.9 ms over 7 frames）；I1 中英文全可切换，英文下无中文（html lang "en", Chinese left: 锦绣飞车 赛车游戏 或上箭头加速 或下箭头刹车 或左右箭头转向）；A3 尊重 prefers-reduced-motion（prefers-reduced-motion is not read）；E2 资源失败有错误界面和重试（1 files refused; no uncaught error; no error screen with a retry）。

## 已解决 · Solved

- 牌匾和横幅上的字上下颠倒：画布从上往下数行、贴图从下往上数，复制像素时逐行倒过来（`src/shapes.mjs`，`1330ced`，ENGINE-NOTES 第 1 条）。 · Writing on the banners and plaque was upside down; rows are copied in reverse (item 1).
- 拿到玉佩时第一次绘制它的材质造成卡顿：给玉佩网格加中性的顶点色，复用赛车已经编译过的着色器（`b8b0c07`，ENGINE-NOTES 第 2 条）。 · The jade charm's first draw stalled; it now reuses the karts' programs (item 2).
- 湖面倒影每帧都重画一次场景：改为每三帧更新一次（`src/scenery.mjs`，`ee391d0`，ENGINE-NOTES 第 3 条）。 · The lake's reflection redrew the scene every frame; it now updates every third frame (item 3).
- 触屏操作不稳，已修正并稳定下来（`ee391d0`、`cde9ae4`）。 · The touch controls were fixed and steadied.
