# 锦绣飞车 · 赛道模型

这批模型在 Tripo Studio 由项目专用文字提示生成。导出后在本地简化网格、调整贴图尺寸，并在白鹭 World3D 里对齐赛车和赛道。GLB 内嵌材质贴图，浏览器通过 `index.json` 加载。

| 用途 | 模型 |
| --- | --- |
| 赛车和车手 | 醒狮车身与头模、熊猫车身与坐姿车手、猴王车身与头模 |
| 地标 | 起点牌楼、湖畔宝塔 |
| 加速与减速提示 | 祥云门、滚鼓、石狮 |
| 拾取物 | 近处的道具灯笼 |

赛车的动态车轮、原有车手动作和机械部件由游戏控制。牌楼沿原赛道加宽开口，沿用双面牌匾。重复道具使用实例化，远处拾取物沿用轻量几何。碰撞、加速触发和道具规则仍取自赛道和比赛模拟数据。

文件名与加载位置须在 `index.json` 中对应。模型的默认前向为 +Z。滚鼓在加载时绕 X 轴旋转到横卧姿态。编辑模型后，核对选车预览、追车视角、近处拾取物和两座门的通行净宽。打开 `?models=original` 可查看原美术用于对照。
