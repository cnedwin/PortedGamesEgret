# 洗冤笔录 · 美术来源 · The Inquest Scrolls: where the pictures come from

基于新白鹭引擎独立开发的宋代刑侦推理游戏 Demo。游戏里的每一张图都由下面的提示词用文生图生成，没有使用、临摹或参照任何他人的画作；提示词只描述题材、器物和宋代绢本设色、工笔重彩的画法，不点名任何作品或画家，并要求画面里没有文字、印章和落款。界面（卷轴、宣纸、朱印、词签、字盘）不是图片，由引擎绘制。

A Song-dynasty detective deduction game demo built independently on the new Egret engine. Every picture in the game was
generated from the prompt below by text-to-image; no one else's painting was used, copied or referred to. The prompts
describe only the subject, the objects and the manner of Song gongbi painting on silk, name no work or painter, and ask
for no text, seal or signature in the picture. The interface (scrolls, paper, seals, slips, the board) is not a picture:
the engine draws it.

## 生成与处理 · How they were made

| 项 · Item | 做法 · How |
|---|---|
| 生成 · Generation | Tripo 命令行 `tripo generate text-to-image`，2026 年 11 月。背景用 `seedream_v4`，3840×1440；人物、器物和人形图用 `chat_image_2.5_flare`，透明底 PNG，质量 medium。 · The Tripo command line, November 2026: backgrounds with `seedream_v4` at 3840 × 1440; figures, things and charts with `chat_image_2.5_flare` as transparent PNG. |
| 提示词表 · The prompt table | [tools/assets/art.tsv](../tools/assets/art.tsv)：编号、种类、尺寸、完整提示词，下表照录。 · id, kind, size and the full prompt, copied below. |
| 打包 · Packing | [tools/assets/pack.py](../tools/assets/pack.py)：去掉透明边，人物最长边 1000、器物 900、人形图 1100，背景 3840×1440 另出一张半尺寸的低画质版，全部存为 WebP；尺寸写进 `assets/art/index.json`。两张背景裁过边（见下表）。 · Transparent edges trimmed, figures to 1000 px, things 900, charts 1100; each background also at half size for low quality; all WebP, sizes in `assets/art/index.json`; two backgrounds cropped (see below). |
| 摆放 · Placing | [src/view/scenes.mjs](../src/view/scenes.mjs) 写每案每张图的位置、高度和层次；[tools/assets/preview.py](../tools/assets/preview.py) 把一案拼成一张预览图，用来对证物的点按区。 · positions, heights and layers per case; a preview script composes a case to check the tap areas. |
| 小游戏 · Mini game | [tools/wechat.mjs](../tools/wechat.mjs) 再缩小一遍（人物 560、器物 420、人形图 760），WebP 转为 JPEG 或带透明的 PNG。 · shrunk again for phones and written as JPEG or PNG. |
| 未用的图 · Not used | 一张印章图（`p-seal`）生成后画面里出现了可读的字，已删去；印章改由引擎画。 · one seal picture had legible characters in it and was dropped; seals are drawn by the engine. |
