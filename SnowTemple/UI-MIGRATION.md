# 原生界面迁移 · Native UI migration

## 版本与边界 · Version and scope

引擎由 `8e70dcb3` 升至 `e15aabcf742ec7c82ba4a8e8c2de663137c18f71`，先以独立提交 `07639ada` 验证旧界面。运行时由官方 `tools/vendor-game.mjs` 生成。规则、伤害、敌人行为、档案键名与结构、高中低模型和角色分阶段加载、场景、配乐与中文语音不改。

The engine advances from `8e70dcb3` to `e15aabcf742ec7c82ba4a8e8c2de663137c18f71`. The independent upgrade commit `07639ada` retains the old interface for regression. The runtime is generated by the official vendor tool. The rules, damage, enemy behaviour, save keys and format, three model tiers and staged role loading, scene, music and Chinese voice acting are unchanged.

## 布局、输入与图形 · Layout, input and rendering

- `createWorld3DOverlay` 叠加在原 World3D 画布上，`fit: 'expand'`，960×540／480×840 设计尺寸，`uiScale` 最低 44/48，最高 1.25。所有页面依据 `game.screen.safe` 排布。`onScreenChange` 重排现有叠加层与屏幕栈，不重建战斗和 3D 引擎；交互空白区交还场景。· The native overlay uses expand fit, the stated landscape/portrait design dimensions and CSS scale bounds. Safe-area layout reflows the existing overlay/stack without rebuilding the battle or the 3D engine. Empty interactive regions pass through to the scene.
- 使用 `renderMode: 'on-demand'` 与 `webgl2PageBatching: 'single-page'`。战斗 HUD 数值以固定字形纹理及保留的原生网格绘制，非动态菜单采用引擎图集文字。· The overlay is on-demand with single-page WebGL2 batching. A fixed glyph texture and retained native meshes draw changing counters, while statically labelled menus use engine atlas text.
- 游戏键鼠与触屏仍写入原来的输入记录；触屏摇杆保留按压幅度，按住攻防／踏雪随触点终止释放。设置中禁用战斗输入，改键仍接受键盘和鼠标。· All devices still feed the original input record. Analog stick magnitude and independent held actions end with their contacts. Settings suppress combat inputs while rebinding remains available.
- `createUiRoot`、`createUiLayerManager` 与 `createUiScreenStack` 管理原生页面和模态。非可见操作不应进入当前语义树；语义名称映射到实际控件，不另绘 DOM 交互层。· Native root, layers and screen stack manage pages and modal controls; semantic names map to real controls rather than a separate DOM interface.
- [i18n.mjs](src/i18n.mjs) 在显示层翻译对话、道具、等级、目标、事件、技能和菜单；支持设置切换及 `?lang=zh|en`。原始语音保留中文，英文使用字幕翻译；规则和存档仍保存原始 ID 与评等。· Translation is confined to the presentation layer. Chinese recordings are retained with English subtitles in English mode; rule identifiers and saved marks remain unchanged.

## 复跑 · Reproduce

在游戏目录运行 · In the game directory:

```sh
node --test test/*.test.mjs
node test/accept.mjs
node vendor/egret.mjs verify
node vendor/egret.mjs verify --screens --play test/screen-route.mjs --playwright test/screen-browser.mjs --out ../../snowtemple-screen-evidence
```

设置 `SNOW_HARDWARE=1` 与本机浏览器 `CHROMIUM_PATH` 可复跑完整版硬件验收及硬件浏览器多屏检查；`SNOW_SCREEN_SHORT=1` 运行实际标题、设置、开场、雪路和行囊五状态路线（本轮九种尺寸实测）。默认的多屏脚本包含完整章节，软件绘制设备耗时较长。多屏尺寸模拟不等于手机真机。 · Set `SNOW_HARDWARE=1` and an installed `CHROMIUM_PATH` for the complete hardware acceptance and hardware-browser screen checks. `SNOW_SCREEN_SHORT=1` selects the five-state actual route measured on nine profiles. The default screen route includes the full chapter and may take longer in software. Simulated viewport profiles do not replace physical-device tests.
