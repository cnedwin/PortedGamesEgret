# 对白配音

林冲用沉稳、厚实的中低音，开场压住怒意，在草料场迎敌时发力。陆谦的音色更冷、更紧。见面带轻蔑，威胁轻慢，失势时怒喝，败退时转为带气声的低语。

八条原创对白由 [Qwen3-TTS 1.7B VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign/tree/5ecdb67327fd37bb2e042aab12ff7391903235d3) 的离线模型生成，模型作者标注 Apache 2.0 许可。每个角色有固定的声线方向，各句独立控制情绪和停顿。录音为 24 kHz 单声道 MP3，游戏按场景加载。
