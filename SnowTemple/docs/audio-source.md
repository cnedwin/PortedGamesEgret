# 风雪山神庙的原创配乐与音效

全部配乐、环境声和音效均用本项目的 [声音生成器](../tools/render-audio.mjs) 合成。旋律由本项目编写，拨弦、箫、低弦、鼓和金属的声部用不同的振动和音色模型生成，风雪、余火和衣物等效果用独立的噪声和共振模型生成。没有使用外部乐曲、音源、录音或音色库。

| 文件 | 发声时机 | 编配 |
| --- | --- | --- |
| title.wav | 第一次点开始后的片头 | 箫先奏四音主题，拨弦在后面回应 |
| road.wav | 风雪山路及庙门 | 稀疏拨弦和长音，留出风雪和脚步声 |
| yard.wav | 草料场两波交锋 | 木梆、短拨弦和较紧的鼓点 |
| boss1.wav | 陆谦第一阶段 | 低弦领奏，鼓点之间留出空隙 |
| boss2.wav | 陆谦第二阶段 | 同主题移至高声部，鼓阵加密，钹用在重拍 |
| end.wav | 转入结尾 | 旋律逐步下行，经钟磬收束，播完结束 |

环境声分为山风、余火、庙前。脚步按雪地与石地切换。主角倒下的衣物、喘息声音和着地闷响分别跟随动作开始和接触地面。格挡、弹反、不可格挡招式以及真实的回马枪命中有独立的音效。首领预警和关键接触会暂时压低配乐，密集落枪对叠声设限。

浏览器授权从开始按钮的点按开始。菜单与开场音效使用独立的 331 KB 声库，先于完整战斗声库加载。阶段配乐按需解码，切场时渐变，暂停和静音用独立的总线控制。恢复后不会补发静音期间的声音。

运行下列命令可重建音频并验证文件格式、循环接缝、声库索引和播放调度。每次生成结果相同，游戏运行时只需要浏览器。

~~~sh
node tools/render-audio.mjs
node --test test/audio-assets.test.mjs test/audio-scheduling.test.mjs
~~~
