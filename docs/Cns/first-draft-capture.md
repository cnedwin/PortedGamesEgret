# 首稿开场录像规程

在查看任意首稿前固定本规程。英文原件的 SHA-256 为 `684792b0160b64893cdba0743d8b28113fdecc524bf05f8d95bef6a4f0b026fd`。[英文原件](../first-creation-study/protocol.md)

- 两组使用同一句需求、同一模型配置、工具条件及资源预算。实验改变创作入口。保留两组的原始回复和哈希，超限或运行失败照实登记。
- 使用同一台 Windows 电脑、Chrome for Testing 157、软件 WebGL2、960 × 540、1 倍像素比、中文和默认动画设置。浏览器配置和存储分别从空白开始。
- 从导航开始录满 20 秒，保留加载和停顿。按合成帧原始时间采样成片，两组均无声。录像用于观察开场表现，机器速度未针对性能比较校准。
- 在第 4、8、12、16 秒，每次最多执行一个有可见线索的操作。必要时先开始，再选址或建造、确认，最后在提示出现时接客。完成则等待。操作位置可先在一次性会话中仅凭画面和可访问名称确定；未出现相应操作时保留等待。
- 在 0、4、8、12、16、20 秒附近观察。记录场景是否可玩、目标是否可读、可选位置、同一处物体操作前后的变化和加载错误。资源数字和建筑变化分开记。
- 首次玩家需独立参与。记录首次自主操作、是否需要提醒，以及对“你是谁、能做什么、场景哪里变了”的回答。[玩家观察卡](../first-creation-study/player-card.md)
