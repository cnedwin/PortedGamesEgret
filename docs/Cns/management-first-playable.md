# 经营游戏的第一段可玩体验

先决定玩家进入哪个地方、能亲手选择什么、做完后场景中的哪个对象会留下变化。《河湾筑家》的开场让一家人从岸边搬进玩家选址建成的屋子。一个镜头里能看到选址、预览、动工和入住，换题材时也要为这些动作找到符合新世界的角色与结果。

## 从一句话到第一版

1. 写下这个世界里的一个动词和一个受它影响的对象。用朴素的一句话写出谁在等、缺什么、做完之后谁会改变行为。让玩家进入场景就能找到这件事。
2. 布置两三个可选择的位置或对象。用轮廓、人物朝向或场景内的标记引导视线。选中时能在原位置预览并取消，确认后才扣资源。
3. 给这个动词安排开头、中段和结果。木架立起、屋顶落定、住户走向屋门，是一个决定带来的三个可见后果。随时关掉声音或减少动态，仍能从轮廓和状态读出结果。
4. 用已有的场景规则管理选择、费用和最终状态，让键盘、点击和触摸提交同一个动作。保留读档与退出的约定；设置、语言和文本辅助可从场景进入。第一轮集中在这个动作上，再增加其他系统。

更换题材时，同时更换需要帮助的人、资源用途、场景道具、玩家动词和完成后的行动。保留贴图的脚点与透明边缘，可以把预览、施工和成品安全替换成同一位置的一组新素材。美术目录说明了图幅、位置和许可。

增加常驻侧栏之前，先把它收起看一次开场。把下一步操作放在它影响的人物或地块旁。如果还得读任务清单才知道该做什么，就调整场景或现场提示。已有素材能表达的部分优先复用，把编辑预算留给新玩法。

## 原样观察首稿

保留第一次生成的文件，以及打开到第一次操作后约 20 秒的画面。请未接触过作品的玩家独立尝试，再请对方指出自己在帮谁、改了哪个地方、发生了什么。记录首次主动操作、是否需要解释和因果不清的地方。浏览器脚本可以验证资源扣减与画面变化；玩家是否理解应由试玩回答。

从仓库根目录运行 `npm run create -- MyVillage --template management --title "溪边小镇 · Riverside Town"`。生成目录包含可独立运行的引擎副本、游戏素材、两种语言的指引和测试。
