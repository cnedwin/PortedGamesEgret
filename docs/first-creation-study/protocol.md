# First-draft opening comparison

Freeze this protocol before either generated draft is inspected.
- Identical player brief, model configuration, tools, limits. Candidate condition = offered creation entry. No human edits, dependency improvisation, alternative generation or cherry picking. Both original submissions are hashed.
- Same Windows machine, Chrome for Testing 157, software WebGL2/ANGLE, fresh browser + storage, localhost, identical 960×540 CSS pixels, 1× scale, zh-CN, no reduced motion. Untuned OS speed; this compares appearance and first action, not performance.
- Silent video begins with navigation and runs for 20.000 seconds of wall clock. Include the first blank/loading seconds. Composite captures retain their real timestamps and are sampled on a fixed video time base. No montage, pause removal, speed change or manual polishing.
- Observe at 0/4/8/12/16/20 s. At 4, 8, 12 and 16 seconds, a scripted driver may perform at most one visible action: enter if a title blocks play, choose an apparent build site or construction action, then confirm if requested, then pick up a waiting passenger when prompted. After completion, observe instead of issuing extra inputs. An independent disposable exploration may map clearly visible cues to coordinates or accessible names; no code, diagnostic state or hidden selectors to discover the route. When no matching visible affordance exists, wait. Record what each probe saw and which visible coordinates it used. This is an operator-guided scripted comparison, not a naive player.
- For each draft record whether a playable scene appears, a goal is legible, the player can target a site, and a visible local change persists after action. Capture a before/after same-view screenshot and the relevant plain-language observations. A changed number alone is reported separately from a changed world object. Keep load errors.
- No recruited players in this automated run. Questions for a first-time player: who are you, what can you do first, what changed and where? A human conclusion requires independent unprompted participants. One paired generation supports only a case observation, not a general model or speed claim.
