# First-time player observation card · 初次玩家观察卡

Use this card with a fresh local save in one randomly assigned build. Hide the other build, its condition and the producer's brief. Capture whether the player could act before asking questions. Ask permission separately before recording a person. This card has no participant data.

给首次接触游戏的玩家随机分配一个版本，使用干净存档；隐藏组别、另一个版本和生成需求。先让玩家自行操作，之后提问。录像或记录真人前另行征得同意。本卡尚无参与者数据。

| Prompt · 提问 | Anonymous verbatim answer · 匿名原话 |
|---|---|
| Who are you in this scene? · 场景里的你是什么身份？ | |
| Which action did you try first, and why? · 你先尝试了什么，为什么？ | |
| What changed on screen because of your action? Point to the location. · 你做完以后，哪里发生了什么变化？请指给观察者看。 | |

Record time to first meaningful action, reopens or mistaps, the visible object before/after, and whether any hint was given. Separate objective progress from an explanation offered spontaneously by the player; record uncertainty verbatim. If no action is taken in 20 seconds, keep that observation and do not substitute an instructed success. Do not claim percentages from empty or tiny samples.

记录首个有效动作的时间、重复或误触、动作前后对象的可见变化，以及是否收到提示。操作推进与玩家自主描述分别记录；不知道或犹豫也照录。20 秒未操作时保留原结果。空样本与极小样本不推算理解率。
