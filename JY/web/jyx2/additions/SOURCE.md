# JYX2 画面补绘

头像 114 对应 4in1 的同编号角色，由本项目绘制并保留原有人物识别特征。

同一工具按原创道具描述绘制六张物品图标，分别用于康倍特（0）、白嵐氏雞精（2）、金牛運功散（10）、寶濟丸（21）、六脈神劍譜（66）和飛刀（98）。图标按道具格裁切为带透明背景的 PNG。其余图标由 KYS 本机资源回退。

29 种常用武学的出手与命中光效由 `../effects/combat-art.mjs` 程序绘制。野球拳用冷蓝气流，六脈神劍用蓝白剑气，胡家刀法用浅金刀弧。常用招式另包括寒冰神掌、七傷拳、降龍十八掌、九陽神功、獨孤九劍和玄鐵劍法等。出手光效使用原投射物的方向和寿命，命中闪光使用原碰撞位置和战斗帧号。同一原作特效编号下的不同招式按武学编号应用各自光效。
