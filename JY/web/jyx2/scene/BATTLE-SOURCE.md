# JYX2 战场素材

26 张战场均以 KYS 原版 `warfld` 的地面与建筑格点为依据，默认 140 场战斗使用其中 22 张。雪地、林地、村落、林家院落和聖堂使用独立的场景布局。其余战场沿用探索场景的 JYX2 地表、植被、墙体与家具，特殊图块保留 KYS 图像和原作锚点。战斗命中、地形阻挡、出战位和脚本仍由 KYS 经典回合制规则 决定。

草地、木纹及铺地材质取自本移植的 `home3d/scene.glb` 中的 `Unity Terrain layer blend`、`Wood_1`、`Ground_02`。同一场景的 `Tree_10_2_(1)`、`Tree_09`、`Tree_12` 子树单独封装为 `battle-trees.glb`，保留原版网格和材质。角色、地面和随风摆动的树木使用同一方向光投影。角色原图、武学轨迹和受击特效在 3D 场景中定位并随墙体遮挡，受击范围与出招计时沿用原作状态。

默认经典模式的 140 条战斗记录、固定友军和 Cifa 招募脚本共覆盖 289 个角色编号，对应 92 种外观。同门弟子和成群异兽按原版头像编号共用模型与材质，每个单位各自播放动画。游戏只加载当前出战名单涉及的模型。导入其他数据时，角色编号与头像编号都匹配才能使用这套模型。

人物、门派、大雪怪、大蜘蛛和蟒牯朱蛤沿用 JYX2 模型及动作来源。巨蟒和大鱷魚是为本 Demo 制作的可动模型。独立角色优先按原武学绑定出招动作，部分门派按兵器和武学类型共用动作。小蝦米和段譽的来源见 [主角模型清单](../inn3d-actors/manifest.json)，复用的剧情模型见 [剧情模型清单](../actors/story-models.json)，其他模型见 [战斗模型清单](../actors/battle-model-sources.json)。JYX2 资源固定在 `773f3e76492f4af277e8c93ced2c8d18ba516f6c`。

衣料光泽和贴图采样由白鹭 World3D 材质处理。本 Demo 制作的兵器随角色握持手的骨骼运动。
