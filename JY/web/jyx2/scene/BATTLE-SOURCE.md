# JYX2 战场素材

26 张战场均以 KYS 原版 `warfld` 的地面与建筑格点为依据，默认 140 场战斗使用其中 22 张。雪地、林地、村落、林家院落和聖堂使用独立的场景布局。其余战场沿用探索场景的 JYX2 地表、植被、墙体与家具，特殊图块保留 KYS 图像和原作锚点。战斗命中、地形阻挡、出战位和脚本仍由 KYS 模式 3 决定。

草地、木纹及铺地材质取自本移植的 `home3d/scene.glb` 中的 `Unity Terrain layer blend`、`Wood_1`、`Ground_02`。同一场景的 `Tree_10_2_(1)`、`Tree_09`、`Tree_12` 子树单独封装为 `battle-trees.glb`，保留原版网格和材质。角色、地面和随风摆动的树木使用同一方向光投影。角色原图、武学轨迹和受击特效在 3D 场景中定位并随墙体遮挡，受击范围与出招计时沿用原作状态。

小蝦米及段譽复用 `inn3d-actors` 的原版模型。何太沖、唐文亮、岳不群、林平之和慕容復复用剧情模型及对应的 JYX2 出招动作。动作与模型来源见 [剧情模型清单](../actors/story-models.json)。JYX2 资源对应版本为 `773f3e76492f4af277e8c93ced2c8d18ba516f6c`。
