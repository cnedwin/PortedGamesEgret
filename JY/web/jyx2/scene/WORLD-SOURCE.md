# 江湖大地图与行船素材

地形、房屋、树木、山石、桥梁和家具优先复用项目已获授权的 JYX2 模型。大地图基于 KYS 的原作格点绘制实时透视，使用同一方向光驱动投影。地形高度、地表雾、台基和模型比例仅影响画面，建筑占地、可行走格、出入口和乘船条件仍由 KYS 原作数据确定。

新版 `world-ship.glb` 来自 `cnedwin/jynew` 的 `773f3e76492f4af277e8c93ced2c8d18ba516f6c`。船体为 `OldShip.FBX`，原版两个材质使用 `Tex_OldShip_01.jpg` 和 `Tex_OldShip_02.jpg`。船体按格点比例缩放，保留模型与原贴图。桅杆、帆、索具和尾流在移植项目中制作。主角在水域切换为随船甲板位置，步行和船行共用原作方向与移动输入。 [原版船模目录](https://github.com/cnedwin/jynew/tree/773f3e76492f4af277e8c93ced2c8d18ba516f6c/jyx2/Assets/3DScene/Model/Common/Transportation)

`world=2d` 可选择原作等距画面。
