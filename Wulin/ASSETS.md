# 素材台账 · Asset ledger

每件随游戏分发的第三方素材都记在这里：来源、授权、能否商用、用在哪里。

Every third-party asset shipped with the game is listed here: where it came from, its licence, whether it may be used commercially, and where it is used.

| 素材 · Asset | 来源 · Source | 授权 · Licence | 可商用 · Commercial use | 用途 · Used for |
|---|---|---|---|---|
| 立绘、场景画、界面样式 · portraits, scene paintings, interface styles (`art-handoff/`) | 本项目自制，绘制提示见 `art-handoff/portrait-prompts.json` 与 `assets/scenes/scene-prompts.json` · made for this project | 本项目所有 · owned by the project | 可 · yes | 界面与人物 · interface and characters |
| 引擎构建 · engine build (`vendor/`) | [Egret Rebuild](https://github.com/cnedwin/Egret_rebuild)，见 `vendor/SOURCE.md` | Apache-2.0 | 可 · yes | 3D 绘制 · 3D rendering |

除引擎外，目前没有随游戏分发的第三方素材。3D 的人物、建筑和场景模型都由 `src/view` 中的代码生成；游戏中的文字、数据、界面和代码均为本项目原创。

Apart from the engine, no third-party assets ship with the game yet. The 3D figures, buildings and scenery are generated by the code in `src/view`; the game's text, data, interface and code are original to this project.
