## Engine commands · 引擎命令

In a game made with an engine checkout (`--engine`), `node vendor/egret.mjs guide <question>` asks the engine's guide, `node vendor/egret.mjs card genre-management` gives the recipe for a management game, `check` reads the game for engine names and common mistakes, and `verify` runs it in a headless browser and lists the engine's warnings.

用引擎仓库（`--engine`）建出的游戏里，`node vendor/egret.mjs guide <问题>` 查引擎指南，`node vendor/egret.mjs card genre-management` 给出经营类游戏的配方，`check` 检查引擎名字和常见误用，`verify` 在无头浏览器里运行游戏并列出引擎告警。
