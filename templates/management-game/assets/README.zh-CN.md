# 河湾村落美术资源

[English](README.md)

河岸、木桥、梯田与远处村庄绘制在同一张像素网格上。选址时房屋以浅色轮廓呈现，施工时露出梁柱，入住后能看见暖色瓦片和门前灯笼。住户有独立贴图，可以离开房屋走动。

| 文件 | 原图尺寸 | 摆放方式 |
| --- | --- | --- |
| `village.png` | 480 × 270 | 铺满 960 × 540 舞台。 |
| `house-preview.png` | 80 × 64 | 将底边中心对准所选地块。 |
| `house-frame.png` | 80 × 64 | 施工时沿用预览的锚点。 |
| `house-ready.png` | 80 × 64 | 在同一锚点替换梁柱。 |
| `resident.png` | 12 × 20 | 将底边中心对准住户所在位置。 |

三处地块的舞台坐标分别为 (254, 360)、(506, 314) 和 (740, 348)。贴图按原尺寸的两倍绘制。换题材时可直接替换同尺寸 PNG，也可移动地块锚点，让角色和建筑落在新地景的正确位置。

这五张 PNG 和绘图源文件在 AI 辅助下为本样板原创。生成器用坐标绘制图形，用固定种子控制植被变化，无需外部图片或字体。五张图和生成器使用 [Apache License 2.0](LICENSE)。

如需重新绘制，在装有 Python 3 和 Pillow 的环境中运行 `python draw-village.py`（已用 Pillow 13.0.0 验证）。输出会写在脚本所在目录。游戏运行时只需要 PNG。
