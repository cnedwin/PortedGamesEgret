# Wrapping a label to a width by hand

`game.createLabel` breaks lines only at `\n` and has no width option; `@egret/engine/paragraph` wraps properly but needs its own font resources and provider. For a few lines of help or a hint, insert the breaks yourself and give the label a `lineHeight`.

```js
function wrap(text, width, size, chinese) {
  const lines = [];
  let line = '';
  if (chinese) {
    const per = Math.max(4, Math.floor(width / size));          // CJK: about one em a character
    for (const ch of text) {
      if (line.length >= per && !'，。、；：！？）」'.includes(ch)) { lines.push(line); line = ''; }
      line += ch;                                                // closing marks never start a line
    }
  } else {
    const per = Math.max(8, Math.floor(width / (size * 0.52))); // Latin: about half an em a letter
    for (const word of text.split(' '))
      if (line && (line + ' ' + word).length > per) { lines.push(line); line = word; }
      else line = line ? line + ' ' + word : word;
  }
  if (line) lines.push(line);
  return lines.join('\n');
}
await game.createLabel({ text: wrap(help, 400, 15, zh), fontSize: 15, lineHeight: 23 });
```

Rules:

- Wrap again whenever the language or the layout width changes; the estimate is per font size.
- Count the lines (`text.split('\n').length * lineHeight`) to place what comes below, so buttons never cover the text.
- Leave a little room: the estimate is not a measurement. The quality check I3 (no English cut off at 390 px) catches misses.
